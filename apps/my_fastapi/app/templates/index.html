Built with modern web technology

Fast, reliable websites powered by Python & HTMX.

This site is built with FastAPI and HTMX, a lightweight combination that delivers fast page loads, simple maintenance, and a smooth user experience. By focusing on server-rendered applications instead of heavy client-side frameworks, we create websites that are easier to scale, easier to maintain, and exceptionally responsive.

🐍

FastAPI

A modern Python web framework known for high performance, automatic API documentation, and clean, maintainable code. It provides the backend foundation that powers the application.

⚡

HTMX

HTMX brings dynamic interactions directly to HTML, allowing pages to update without complex JavaScript frameworks. The result is a faster, more accessible, and more maintainable user experience.

🚀

Built for Performance

Combining FastAPI and HTMX creates a streamlined architecture that minimizes unnecessary complexity while delivering excellent speed, reliability, and scalability.
