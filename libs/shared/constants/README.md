# constants

This library was generated with [Nx](https://nx.dev).

The `@domo/constants` entry point contains runtime-neutral exports. Import
environment configuration from `@domo/constants/server` or
`@domo/constants/client` so server-only and browser-only modules are not loaded
through the shared entry point.

## Running unit tests

Run `nx test constants` to execute the unit tests via [Vitest](https://vitest.dev/).
